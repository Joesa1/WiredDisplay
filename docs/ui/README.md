# 工作台界面

状态：当前运行时界面基线。页面资源为 `Resources/mvp-ui-prototype.html`，由 `AppDelegate` 的 `WKWebView` 加载。

## 目的与边界

工作台只负责展示、设备选择和向原生层发起动作。它不直接打开 TCP、创建虚拟显示器、采集屏幕或伪造传输指标。真实状态由原生 `AppDelegate` 回写；浏览器侧只缓存可恢复的展示与设备选择信息。

设备详情以握手中的 `hw.model` 映射已整理的本地资料。已入库的 iMac 显示中文型号、物理面板和透明产品视图；MacBook 显示笔记本图标和已知面板参数，不以 iMac 素材替代。

## 总体布局

窗口整体固定在应用视口内，只有主内容区域可在窗口不足时滚动。侧栏、工具栏和本机状态卡保持固定，避免出现整窗纵向滚动。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ Thunder Display                                                    toolbar   │
├───────────────────┬─────────────────────────────────────────────────────────┤
│ App / device nav  │ role · selected device                                  │
│                   ├─────────────────────────────────────────────────────────┤
│ 本机状态          │ [device identity] [compatibility] [connection status]   │
│ saved devices     │ ------------------------------------------------------- │
│ + 添加设备        │ role: Host | Display                                   │
│                   │ host: output mode, audio relay, prevent display sleep  │
│ 配置检查          │ display: bridge IP, pairing code, listener status      │
│                   │ ------------------------------------------------------- │
│ 屏幕录制          │ metrics: throughput | fps | RTT | codec                │
│ 排列显示器        │ 60-second graph / current-session narrative            │
│ 本地网络          │                                                         │
│                   │ [scrolls only here when height is constrained]          │
│ 偏好设置          │                                                         │
└───────────────────┴─────────────────────────────────────────────────────────┘
```

## 页面与入口

| 页面 | 入口 | 真实数据 | 不可做的事 |
| --- | --- | --- | --- |
| 本机状态 / 当前设备 | 侧栏设备项 | 当前角色、本机 bridge、已选设备、当前会话 | 不得把其他设备的指标展示到当前设备。 |
| 添加设备 | 侧栏“添加设备” | IPv4 与六码配对码 | 首次握手前不得要求用户维护设备名称。 |
| 配置检查 | 侧栏工具项 | 本机 bridge、探测握手结果、目标 profile | 未点击“运行检测”时不得制造速率或屏幕参数。 |
| 屏幕录制 / 排列显示器 / 本地网络 | 侧栏本机配置项 | 系统设置深链接 | 不能把系统授权状态伪装为已授予。 |
| 偏好设置 | 侧栏底部 | 自动重连、菜单栏、图标选择 | 不得承诺未进入原生行为的设置已生效。 |

## 状态与导航

```text
empty device list
  -> 本机状态 (默认入口)
  -> 添加设备 dialog
  -> saved device
  -> first probe / first connection
  -> peer identity replaces provisional endpoint label

saved device
  -> available -> selected -> connecting -> live
                           \-> failed / disconnected (disabled until refreshed)
```

空设备列表时，用户从“配置检查”进入后必须始终能通过“本机状态”回到主工作台。它不是设备列表的占位项目，也不可因为没有已保存设备而失去入口。

侧栏只能有一个选中视觉状态：本机状态和某个保存设备不能同时显示为 active。当前页面只会在另一设备处于 `connectedId` 时禁用设备；`away`/失联设备仍可点击。将失联设备置灰并禁用是 `device-state-001` 的目标，尚未实现。设备条目只展示设备名与必要状态点，不显示会被截断的机型或系统版本。

## 添加与已配对设备

```text
┌──────────────────────────────────┐
│ 添加设备                         │
│ 雷雳桥接地址 [10.10.10.3      ] │
│ 配对码       [123456          ] │
│                    [取消] [保存] │
└──────────────────────────────────┘
```

| 操作 | 原生动作 | 结果 |
| --- | --- | --- |
| 保存首次设备 | `device` | 保存 endpoint 与配对凭据；名称、机型、系统版本仍为“待握手”。 |
| 运行检测 | `test` | 实际建立 probe TCP、验证配对并读取 `DisplayProfile`，不采集屏幕。 |
| 主机连接 | `session`（host） | 使用当前设备凭据开始真实会话。 |
| 显示器监听 | `session`（display） | 进入接收端，显示本机 bridge 地址与稳定配对码。 |
| 忘记设备 | 当前仅删除页面 `localStorage` 记录 | 可删空列表并回到本机状态；原生 `UserDefaults` 凭据清理由 `device-state-001` 补齐。 |

本机配对码是本机持久化身份的一部分。它在断线、刷新和重启监听后保持不变；只有用户显式清除配对状态或重置本机身份时才可以改变。当前同一页面记录可使用保存凭据重连；把两端设备记录收敛为稳定、可双向复用的一键重连模型属于 `device-state-001`。

## 原生 bridge 合同

页面向 `window.webkit.messageHandlers.thunderDisplay` 发送对象，原生层只接受以下动作：

| 动作 | 关键字段 | 原生责任 |
| --- | --- | --- |
| `device` | `address`, `code` | 校验地址、保存首次 endpoint/凭据。 |
| `session` | `role`, `address`, `code`, `output`, `audio`, `preventSleep` | 开始/停止主机或显示器会话。 |
| `test` | `address`, `code` | 发起 probe，不启动媒体。 |
| `refresh` | 无 | 刷新本机雷雳状态；Bonjour 发现器在启动后持续运行，当前动作不直接重启它。 |
| `role` | `role` | 释放当前会话后切换角色。 |
| `preventSleep` | `role`, `enabled` | 更新主机要求或显示器本地息屏偏好。 |
| `preference` | `key`, `enabled` | 保存原生偏好。 |
| `icon` | `value` | 切换运行时 Dock 图标。 |
| `settings` | `page` | 打开对应 macOS 系统设置页。 |

原生层回写的最小集合是：本机配对信息、监听状态、连接状态、对端身份、版本/协议、诊断结果和当前会话指标。页面不得用定时随机数填充吞吐、帧率、RTT 或折线图；没有指标时稳定显示 `—`，直到本会话收到真实 `StreamStatistics`。

## 角色与媒体控制

| 控制项 | 主机 | 显示器 |
| --- | --- | --- |
| 扩展 / 镜像 | 可选；传递给 `ScreenSender` | 只读显示当前接收模式。 |
| 音频中继 | 可选；决定是否请求音频采集 | 只读显示接收状态。 |
| 防止显示器息屏 | 可选；随主机会话传达给接收端 | 可选本地偏好；只在活动接收时持有系统活动断言。 |
| 本机 bridge 与配对码 | 不作为连接目标展示 | 监听时必须清晰展示，供另一台 Mac 第一次配对。 |

“防止显示器息屏”只保持接收端显示会话可见；它不是阻止主机或系统整体睡眠的承诺。

## 对话框与键盘

| 输入 | 作用域 | 行为 |
| --- | --- | --- |
| `Esc` | 打开的 modal | 取消并回到原页面，不修改保存设备。 |
| 点击遮罩 | 添加、忘记、角色 modal | 等同取消。 |
| 保存设备 | 添加 modal | 仅接受合法 IPv4 与六位数字。 |
| 忘记设备 | 忘记确认 modal | 允许删除最后一个设备，随后选择本机状态。 |

打开添加设备 modal 时焦点落在 IPv4 输入框；关闭后焦点回到发起操作的按钮。

## 状态变体

| 状态 | 页面行为 |
| --- | --- |
| 加载 | 状态区显示“正在读取雷雳网桥”或“正在连接”，不虚构成功指标。 |
| 空 | 本机状态提供角色选择、bridge/配对码和添加设备入口。 |
| 错误 | 显示具体层级：bridge 不可用、TCP、配对、协议、录屏、虚拟显示器或编解码。 |
| 忙 | 连接、停止、切换角色期间禁用互斥动作，仍保留断开入口。 |
| 窗口受限 | 侧栏/工具栏固定，主内容区独立滚动；文本换行，不挤压控制尺寸。 |

## 当前实现偏差

本文件将当前实现与维护目标分开。以下问题已登记在 [backlog](../plan/backlog.md)，在修复前不得将其当作已交付能力：页面设备信息同时保存在 `localStorage` 和 `UserDefaults`、失联设备禁用与原生凭据清理缺失、某些偏好只存在 UI 层、旧设备静态样例可能进入真实列表、以及没有真实会话时的指标刷新边界。

## Touch Bar

工具区在“配置检查”后新增 Touch Bar 独立页面；移动端使用已确认的横屏黑色触控布局。服务默认关闭，Mac 配置页负责开关、地址／二维码、配对码和访问重置，并允许分别启用音乐、Agent、天气、应用坞及系统控制。没有雷雳接收设备时仍可使用本功能。

```text
工具                  Touch Bar
  配置检查            [开启局域网访问]
  Touch Bar           地址 [复制] [打开]    [二维码]
                      配对码               [重置访问]
                      音乐      [开关] [播放器]
                      Agent     [开关] [本地桥接端口]
                      天气      [开关] [城市／坐标]
                      应用坞    [开关] [刷新应用]
                      系统控制  [开关]
```

手机先输入 Mac 显示的配对码；认证后展示真实数据。断网显示连接错误，重新连接同步状态但不重放点击指令；权限不足、播放器未运行、Agent Bridge 离线或天气未配置时显示对应原因，不填入设计样例。只有前台页面持续刷新。所有功能关闭时保留明确空态和连接状态。

原生动作、快照字段、认证和功能边界以 [Touch Bar 合同](../architecture/touch-bar.md) 为准。设计稿 `docs/ui/mobile-touch-bar.html` 是独立模拟原型，运行时不得用它代替 `Resources/touch-bar.html`。
