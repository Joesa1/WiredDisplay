# 验证口径

状态：当前验证要求。这里区分自动化检查、构建检查和真实硬件验收。

## 自动化与本地检查

| 检查 | 权威入口 | 覆盖 | 不能证明 |
| --- | --- | --- | --- |
| 传输检查 | `Tests/TransportCheck.swift` | 分片/合帧、超大 payload、断开重连、重复关闭 | 显示、音频、真实 TCP 路径或双机延迟。 |
| 构建脚本 | `build.sh` | arm64/x86_64 编译、包结构、ad-hoc 签名 | 在 Intel、M 系列或另一台 Mac 上的运行时行为。 |
| HTML/bridge 静态检查 | 代码审阅 | 动作名和 DOM 状态的完整性 | 原生回调、系统权限或真实设备状态。 |

`Tests/ReceiverCheck.py` 仍按协议 1 / app `0.2.0` 构造握手，与协议 2 不兼容。它是历史脚本，当前不得作为通过条件。恢复为现行测试前，必须先更新其握手、身份字段、错误断言和协议版本。

## 双机验收矩阵

每次会影响协议、传输、媒体、睡眠、配对、UI bridge 或发布包的改动，至少执行受影响行。

| 场景 | 主机 | 显示器 | 通过条件 |
| --- | --- | --- | --- |
| 首次配对 | M 系列 MacBook Pro | M1 iMac | 显示器显示稳定 IP/六码；主机 probe 读取 profile；握手后名称/型号/系统版本回读。 |
| 已配对重连 | 任一已保存设备 | 同一 iMac | 断线/重启监听后，主机可一键重连；本机配对码不变化。 |
| 扩展 | MacBook Pro | M1 iMac | `2240 x 1260` 逻辑桌面与 `4480 x 2520` Retina 流，首帧稳定、文字清晰、无比例拉伸。 |
| 扩展 | MacBook Pro | 2017 2.5K iMac | `2560 x 1440`，鼠标位置与形状正常。 |
| 镜像 | 任一 | 任一 | 采集主屏幕，不创建额外虚拟桌面；停止后恢复。 |
| 音频 | 任一 | 任一 | 打开/关闭生效；短暂网络抖动不造成持续积压。 |
| 睡眠恢复 | 任一 | 任一 | 睡眠时旧会话和显示窗口释放；唤醒后按设置在 30 秒内有限重连；手动断开不复连。 |
| 菜单栏与窗口 | 任一 | 任一 | 首帧后才显示已连接；关闭主窗口只最小化；退出完整释放资源。 |
| Intel runtime | Apple Silicon host 或 Intel host | 2017 Intel iMac | x86_64 包启动、监听、接收和重连均实际通过。 |

每条结果要记录：两台机型/芯片、macOS、应用版本、协议、bridge 接口与 IP、线材、运行模式、步骤、可复现日志、结果和已知异常。

## 指标口径

| 指标 | 来源 | 显示条件 |
| --- | --- | --- |
| 吞吐 | 当前 `StreamStatistics` 会话样本 | 仅活动且当前选中设备有真实样本时。 |
| 帧率 | 已确认帧的会话统计 | 只显示当前会话；未开始为 `—`。 |
| 往返延迟 | 心跳/确认帧测量 | 不是屏幕到屏幕绝对延迟。 |
| 编码 | 已协商视频配置 | 配置前为 `—`。 |
| 60 秒曲线 | 当前设备最近 60 个真实样本 | 无样本时稳定空态，不闪烁横杠。 |
