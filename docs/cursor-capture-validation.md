# 系统光标随画面传输

## 改动

- ScreenCaptureKit 的 showsCursor 设为 true，将主机实际系统光标合成进桌面采集帧。
- 停止每秒 60 次的独立鼠标坐标发送，避免接收端再叠加固定箭头。
- 首帧确认仍负责更新菜单栏连接状态和停止重连重试，变量改名为 firstFrameAcknowledged。
- 保留旧版光标消息的接收能力；新版发送端不发送这类消息，接收端光标叠加层保持隐藏。

形态由主机操作系统和应用决定，接收端不分析页面、不猜测选择状态。移动和形态变化经过采集、编码、传输、解码与显示，可能比独立光标层更有延迟感。

## 验证

- arm64 和 x86_64 优化编译通过。
- 通用测试包版本 0.6.2-pr1-cursor，构建号 17；独立标识沿用 local.wired-display.test。
- 双机光标行为和延迟尚未实测。建议两端安装此版本。

## 手工验收

1. 在扩展模式和镜像模式分别验证普通区域箭头、网页链接小手、编辑器文本 I 形及窗口边缘缩放光标。
2. 页面保持静止，仅移动鼠标或切换光标形态，确认画面仍更新且没有重影或双光标。
3. 在主屏与扩展屏间移动，确认光标进出正确；检查 Retina 缩放时点击位置是否匹配。
4. 测试窗口拖动、滚动、选中文字，对比上一版本鼠标跟手程度。
5. 断开重连、睡眠唤醒后再次检查光标与菜单栏状态。

先退出旧测试版或正式版，再启动本版，避免端口冲突。此本地测试包未公证。
