# 睡眠恢复、菜单栏与窗口行为

## 改动

- 订阅系统睡眠/唤醒通知，睡眠使旧会话失效；唤醒等待异步清理完成和雷雳接口恢复。
- 只有睡眠前存在连接/监听/连接请求时才恢复；主机遵循自动重连偏好，接收端恢复监听。用户主动断开会取消重连。
- 菜单栏重新连接和自动恢复最多等待/重试 30 秒；首帧确认后停止重试。协议/视频错误不无限重试。
- 接收端 TCP 关闭时保留监听，但清理窗口、鼠标隐藏、防息屏、渲染回调和界面连接状态。
- 旧发送器失败回调和首帧回调检查会话身份，不能影响新连接。
- 菜单栏以图标和文字区分已连接、连接中、等待主机、未连接；已连接以首帧显示/确认为依据。
- 支持打开主窗口、断开、重新连接、退出。系统模板图标支持深浅色菜单栏。
- 主窗口红色关闭按钮执行最小化；点击 Dock 图标或菜单栏“打开”可恢复。视频窗口关闭仍表示停止显示。退出使用菜单或 Command-Q。
- HTML 偏好设置同步到原生，包括初始化和恢复默认设置。

## 双机验收

1. 两端运行修改版，建立连接。首帧出现后菜单栏显示已连接。
2. 主机合盖进入睡眠，接收端退出旧视频窗口并显示未连接/等待主机，鼠标恢复。
3. 唤醒主机，检查资源清理后重建视频和虚拟显示器，无须手动关闭黑屏页。
4. 两端同时睡眠及接收端晚唤醒，验证 30 秒内重试、超时可手动重新连接。
5. 关闭自动重连，主机唤醒后不自动发起连接；接收端仍可接受手动连接。
6. 在重连等待期间点击断开；之后恢复网络，验证不会再次连接。
7. 快速重复睡眠/唤醒及重连，检查旧失败回调不关闭新会话、无重复窗口。
8. 主窗口点击红色按钮：窗口进入 Dock、进程和连接保持；菜单栏打开及 Dock 点击均恢复窗口。
9. 菜单栏断开/重新连接/退出和 Command-Q 均有效；退出释放虚拟显示器。
10. 切换菜单栏显示偏好、恢复默认、重启，确认设置和真实图标一致。
